## Archivos principales
- `index.html`: página principal.
- `productos.html`: catálogo completo generado desde JavaScript.
- `detalle-producto.html`: detalle por parámetro `?id=`.
- `registro.html`: registro con validaciones.
- `login.html`: inicio de sesión.
- `contacto.html`: formulario de contacto.
- `nosotros.html`: empresa y equipo.
- `blog.html`, `blog-detalle-1.html`, `blog-detalle-2.html`: noticias.
- `seguimiento.html`: seguimiento demostrativo de pedidos.
- `admin.html`, `admin-productos.html`, `admin-usuarios.html`: vistas administrativas.
- `estilos.css`: estilos externos y responsive.
- `script.js`: catálogo, carrito con localStorage y validaciones.
